# People images for the tours

Waypoints may carry an optional `image` (path relative to the tour page) and
`image_caption`. `tour-common.js` hides the figure if the file 404s, so a
waypoint can name a headshot that has not been added yet.

Expected filenames, referenced by `waypoints_research_group_public.json`:

|------|--------|
| `group_photo_2025.jpg` | group photo (present) |

| `budaiev.jpg` | Nazar Budaiev |
| `jeff.jpg` | Desmond Jeff |
| `yoo.jpg` | Taehwa Yoo |
| `richardson.jpg` | Theo Richardson |
| `garcia_santa_maria.jpg` | Miriam Garcia Santa-Maria |

Drop in square-ish JPEGs (~400x400 is plenty; the panel renders at 190 px).
Get each person's permission before publishing their photo.
